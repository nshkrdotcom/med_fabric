    Med Fabric

    Med Fabric is a deployable Elixir reference exam that brings together two-way WebRTC talkback, live diagnostic audio capture with MedEx, and clinician review of recordings and pulse-rate measurements. PostgreSQL records acceptance and queues HL7 FHIR R4 delivery.

    Run the exam candidate

    The 0.2 candidate combines two-way conversation, independently selected diagnostic audio and clinician-entered pulse measurements. A patient can recover a recording outcome after reconnecting. Clinicians can seek in a verified WAV, review its source and time, and deliver the accepted observation to the encounter’s own FHIR destination.

    From this checkout, with MedEx checked out alongside it, run the SDK and Fabric QC sequence:

    bash ops/qc_candidate.sh

    The command prepares the SDK's Weld release bundle, checks its browser assets, and runs the exam release against that exact bundle's project/ directory. Commit SDK source changes first: Weld requires a clean source revision. The candidate dependency lock stays under apps/exam/_build/. Allow time for native dependencies, Dialyzer, PostgreSQL, HAPI and Chromium. For a live exam, follow the operator setup. For an actual TURN demonstration use the two-endpoint media procedure.
