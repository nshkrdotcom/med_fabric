    Healthcare record exchange

    mf_interop (core/interop) is the single authoritative healthcare record exchange library for Med Fabric (kept outside MedEx). It maps accepted observations into HL7 FHIR R4 Observation resources and delivers them idempotently over HTTP using Req.

    Delivery

    MedFabric.Interop.FhirClient maps reviewed recording digests (reviewed-auscultation-recording) and manually entered pulse rates (LOINC 8867-4, UCUM /min) into distinct FHIR R4 Observation payloads. It uses conditional create (If-None-Exist) and confirms remote identity and clinical values on read-back, including the presence or absence of a quantity comparator.

    Use FHIR_BASE_URL and mix test integration to exercise retry against native HAPI. See the browser-to-record guide.
